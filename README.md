## 🎯 Overview

This repository contains practical Java software applications developed to demonstrate core computer science fundamentals, modular class design, user input handling, and state management.

---

## 📦 Included Applications

### 1. 💰 Expense Tracker Application (`ExpenseTrackerApp.java`)
- **Description:** A personal finance tracking utility allowing users to log incomes, categorize expenses (Food, Rent, Travel, Utilities), and calculate real-time net balances.
- **Key Features:**
  - Dynamic transaction logging with timestamp and category tagging.
  - Expense summaries and category breakdown.
  - Formatted balance reports.

### 2. 🔗 Link Shortener (`LinkShortener.java`)
- **Description:** A URL shortening service implementation that generates unique, compact alphanumeric aliases for long web addresses.
- **Key Features:**
  - Base-62 / hash-based unique key generation.
  - Bi-directional lookup mapping (Short URL ↔ Long URL).
  - Validation to prevent duplicate or invalid URL mapping.

### 3. 🎮 Text Adventure Game (`TextAdventureGame.java`)
- **Description:** An interactive, choice-driven fantasy adventure game played in the console.
- **Key Features:**
  - Branching decision trees based on user choices.
  - Health point (HP) and inventory tracking.
  - Random encounter mechanics and dynamic win/loss conditions.

### 4. 🧠 Interactive Quiz System (`main.java`)
- **Description:** A structured quiz evaluation engine supporting multiple-choice questions (MCQs).
- **Key Features:**
  - Encapsulated `Question` and `Quiz` classes.
  - Input validation with boundary and exception handling.
  - Final score computation and feedback reports.

## 🚀 How to Run

Compile and execute any application individually:

```bash
# 1. Expense Tracker
javac ExpenseTrackerApp.java
java ExpenseTrackerApp

# 2. Link Shortener
javac LinkShortener.java
java LinkShortener

# 3. Text Adventure Game
javac TextAdventureGame.java
java TextAdventureGame

# 4. Interactive Quiz
javac main.java
java main
```
